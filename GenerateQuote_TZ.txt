ТЗ "Генератор Цитат"

Задача: разработать сетевое многопользовательское приложение "Генератор цитат" которое позволяет генерировать случайные цитаты.

=========================================================

Модуль 1. Сервер.

Клиент подключается к серверу, отправляет серверу команду, и получает результат выполнения команды в качестве ответа.

Сервер должен поддерживать 3 команды (2 обязательных + 1 опциональная):

- ping -> pong: проверка доступности сервера

- get-quote -> <случайная цитата>: получение случайной цитаты

- finish -> в ответ ничего но завершить взаимодействие с клиентом и отключить его - опциональная

=========================================================

Модуль 2. Консольный клиент.

Клиентское приложение для работы с сервером, ввод / вывод через консоль.

=========================================================

Модуль 3. Десктопный клиент (WinForms / WPF).

Приложение для рабочего стало для работы с сервером, ввод / вывод через GUI.

=========================================================

Требования к релаизации ПО:

1. Бизнес-логика системы не должна зависеть от конкретной реализации, а значит не привязываться к:

- источнику цитат: может быть заглушка, чтение из файла, из БД, запрос через API

- сетевые протоколы и формат взаимодействия: В ИДЕАЛЕ система не знает на каком типе сокетов и протоколе работает

2. Должен быть сделан минимум 1 клиент

=========================================================

НАД ЧЕМ ПОДУМАТЬ (решенеи принять):

1. А надо ли делать асинхронное взаимодействие или оставить синхронным?

2. Какой формат подключения - установливать ли перманентную связь с клиентом или делать одно подключение на обработку одной команды? Или сделать гибрид с keep-alive-командой?

3. С какого протокола начать - TCP / UDP?
